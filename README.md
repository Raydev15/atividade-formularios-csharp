# Atividade — Formulários em C#

Projeto Windows Forms em C# para abrir no Visual Studio.

## Abrir no Visual Studio

1. Extraia o ZIP ou clone este repositório.
2. Abra `AtividadeFormularios.sln` no Visual Studio 2022 com a carga de trabalho **Desenvolvimento para desktop com .NET**.
3. Execute com **F5**.

O Formulário 1 contém Nome, RA e o botão **Prossiga**. O Formulário 2 contém E-mail, Endereço, Telefone e os botões **Voltar** e **Salvar**. Voltar mantém Nome e RA; Salvar acrescenta todos os dados e a data/hora em `Documentos\AtividadeFormularios\LOG.txt`.
